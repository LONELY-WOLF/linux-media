# linux-media-rockchip-rga

Rockchip RGA (linux-rga) wrapper for .NET

## API Coverage

3 functions supported:

* **Blit** - copy, cut, scale, rotate, convert, etc...
* **ColorFill** - fill with color
* **Flush** - wait for all operations to finish

## Dependencies

.NET and linux-rga (librga.so)

## Test Environment

This lib was tested on Rockchip RK3588s
